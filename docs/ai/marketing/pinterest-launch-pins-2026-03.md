# Pinterest Launch Pins (March 2026)

The copy for the first Pinterest pins, written when the campaign started on 2026-03-16. Moved here from Ben's notes on 2026-11-13 so the record lives with the rest of the marketing docs.

## Use this when

You want to see what the launch pins said (headline, title, description, hashtags, CTA, link) before writing new pins or repinning an old one.

## Read this first

This is a historical record, not a template. Some of the copy predates the rules in [`pinterest-launch-plan.md`](pinterest-launch-plan.md) and would not pass them today:

- Pin 11 says "the best calming products that actually help"; the plan now bans "actually" in pin copy.
- UTM parameters are inconsistent (`utm_source=Pinterest&utm_medium=organic` on some pins, `pinterest` / `social` / `launch` on others). Use [`utm-rules.md`](utm-rules.md) for new links.
- Several pins have typos in their headlines and hashtags (for example `#donganxiety`). Fix them before reusing.

For any new or reworked pin, follow the launch plan's design and copy rules and the claim guardrails.
